# Talket 구성과 프로젝트별 비교

Talket의 상품·재고·주문은 [README.md](README.md)에 있다. 단어가 프로젝트마다 다른 층을 가리키면 [../용어.md](../용어.md)를 본다. 프로젝트별 대조는 각 폴더의 `talket.md`이고, 아래 표가 그 색인이다.

비교 축은 같다.

| 축 | Talket이 두는 자리 |
|----|-------------------|
| 그릇 | `Product`. 이름, 카테고리, 판매 기간, 배송·환불·확정 정책 |
| 파는 단위 | `ProductOption`. 이름 붙은 칸. 가격·정원·인당 한도가 여기 |
| 권리 1개 | 결제 후 `ProductItem` 행. id는 주문 제출 때 정해 둠 |
| 재고 | `totalCount`에서 결제 확정 줄의 `currentQuantity` 합을 뺌 |
| 홀드 | 카트는 수량만. 바로구매 ID 풀은 선택 |
| 주문 | `Order` + 옵션별 `OrderLine` + 수량만큼 `OrderItem` |
| 이행 | 티켓은 소유·사용, 굿즈는 배송. 주문 테이블은 하나 |
